# Reports

This folder contains the exported analysis outputs for the Energy Analytics & Sustainability Reporting Platform.

## Contents

- `audited_data.csv` - dataset exported after the audit notebook
- `cleaned_data.csv` - cleaned and analysis-ready dataset
- `final_energy_analysis.csv` - final analysis outputs and summary metrics
- `missing_values_report.csv` - missing-data diagnostics
- `figures/` - exported charts, screenshots, and other visual assets

## How to Use This Folder

Add charts or screenshots to `reports/figures/` when you want the project documentation or reporting package to include visual evidence alongside CSV outputs.

Recommended file types:

- PNG for charts and screenshots
- SVG for vector exports
- PDF for static report pages

If the workflow expands, keep figure filenames descriptive and tied to the notebook or KPI they support.
