# Data

Project data lives in the `data/` and `reports/` directories.

- `data/raw/` — Original raw datasets (source CSVs).
- `data/processed/` — Processed datasets used by notebooks and scripts.
- `reports/audited_data.csv` — Output from the data audit notebook.
- `reports/cleaned_data.csv` — Output after cleaning.

When re-running analyses, regenerate the processed data by running the cleaning notebook or `src` utilities.
