# Notebooks

This project includes Jupyter notebooks used for auditing, cleaning, and analysis.

- `notebooks/01_data_audit.ipynb` — Data audit and initial quality checks; saves `reports/audited_data.csv`.
- `notebooks/02_data_cleaning.ipynb` — Data cleaning steps and imputation decisions.
- `notebooks/03_exploratory_analysis.ipynb` — Exploratory analysis and visualizations.

Open the notebooks in Jupyter or VS Code to run them interactively.
