# Data Dictionary

## Dataset Overview

ASHRAE Building Energy Consumption Dataset

Purpose: Analyze building energy consumption, identify efficiency opportunities, develop KPIs, and support sustainability reporting.

| Column | Description |
|----------|----------|
| building_id | Unique building identifier |
| meter | Meter type identifier |
| timestamp | Date and time of energy reading |
| meter_reading | Recorded energy consumption |
| site_id | Site/location identifier |
| air_temperature | Outside air temperature (°C) |
| cloud_coverage | Cloud coverage level |
| dew_temperature | Dew point temperature |
| precip_depth_1_hr | Rainfall depth in previous hour |
| sea_level_pressure | Atmospheric pressure |
| wind_direction | Wind direction in degrees |
| wind_speed | Wind speed |
| primary_use | Building category |
| square_feet | Building area |
| year_built | Construction year |
| floor_count | Number of floors |
